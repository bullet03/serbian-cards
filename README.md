# Сербские карточки

Личное приложение для изучения сербского языка — карточки Сербский ↔ Русский,
идея как у AnkiDroid. Фронтенд без своего сервера, данные хранятся в Firebase
(Firestore + Authentication).

**Сайт:** https://bullet03.github.io/serbian-cards/

## Запуск локально

```bash
cd ~/Documents/serbian-cards
npm run dev
```

Откройте адрес `http://localhost:...`, который появится в терминале.

## Деплой

При каждом `git push` в ветку `main` GitHub Actions (`.github/workflows/deploy.yml`)
сам собирает проект и публикует его на GitHub Pages — вручную ничего заливать
не нужно.

## Как это работает

У каждой карточки есть сербская сторона и русская (перевод или короткое
описание — выбирается при добавлении). Во вкладке **Учить** нажмите на
карточку, чтобы увидеть русскую сторону, и отметьте:

- **Не знал** — карточка вернётся заново совсем скоро.
- **Знал** — карточка будет показываться всё реже (по системе коробок:
  1 → 3 → 7 → 14 → 30 дней).

## Хранение прогресса

При первом открытии нужно зарегистрироваться (email + пароль). После входа
весь прогресс автоматически сохраняется в Firestore — под одним и тем же
аккаунтом данные одинаковые на любом устройстве и в любом браузере, очистка
кеша браузера их не затронет.

Доступ к данным настроен так, что читать и писать в свой документ может
только владелец аккаунта (см. `firestore.rules`) — посторонние, даже зная
адрес сайта, ничего изменить не смогут.

## Вкладки

- **Учить** — повторение карточек, которые пора повторить.
- **Управление** — поиск, редактирование и удаление карточек.
- **Добавить** — добавление новой пары слов (перевод или описание).
